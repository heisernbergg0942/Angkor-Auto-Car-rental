# Angkor Auto Car Rental

Welcome to the Angkor Auto Car Rental project!

This project is a comprehensive car rental web application consisting of two main parts:

## 1. Frontend
The frontend is built using **React**, **Vite**, and **Tailwind CSS**. It contains both the customer-facing portal (for browsing and booking vehicles) and the admin dashboard (for fleet management, customer tracking, and revenue analytics).
- Location: `./frontend`
- Run locally: `cd frontend && npm run dev`

## 2. Backend
The backend is powered by **Laravel**. It provides the API and database management to support the application.
- Location: `./backend`
- Run locally: `cd backend && php artisan serve`
